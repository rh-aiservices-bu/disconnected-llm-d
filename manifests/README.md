## Applying by hand

Most are plain manifests:

```bash
oc apply -f manifests/gateway/gateway.yaml
oc apply -k manifests/qwen2.5-0.5b        # namespace + hardware profile + model
```

Two are **patches**, not whole objects — apply with `--patch-file`:

```bash
oc patch gateway openshift-ai-inference -n openshift-ingress \
  --type=merge --patch-file manifests/gateway/internal-nlb-patch.yaml

oc patch clusterpolicy gpu-cluster-policy \
  --type=merge --patch-file manifests/gpu/clusterpolicy-repoconfig-patch.yaml
```

Two are **templates** with `${VAR}` placeholders — render with `envsubst`:

```bash
envsubst < manifests/gpu/machineset-l40s.yaml | oc apply -f -
```

## The one thing that is deliberately NOT a file

**Enabling OCI ModelCar (Step 6)** has no manifest here, on purpose.

The setting lives inside `inferenceservice-config`, a ConfigMap whose
`storageInitializer` key holds a **JSON document as a string**:

```json
{"image":"registry.redhat.io/rhoai/odh-kserve-storage-initializer-rhel9@sha256:…",
 "cpuModelcar":"10m","memoryModelcar":"15Mi","enableModelcar":true}
```

A static manifest would have to restate every one of those keys, and the image
digest differs per RHOAI version — so committing one would overwrite the
storage-initializer image with a stale digest on somebody else's cluster. The
change has to be computed from the current value:

```bash
desired="$(oc get configmap inferenceservice-config -n redhat-ods-applications \
  -o jsonpath='{.data.storageInitializer}' \
  | jq -c '.enableModelcar = true | del(.uidModelcar)')"

oc patch configmap inferenceservice-config -n redhat-ods-applications --type merge \
  -p "$(jq -n --arg v "$desired" '{data:{storageInitializer:$v}}')"
```

Use `jq`, never `sed` — editing that string textually produces a ConfigMap
KServe cannot parse and a controller that CrashLoops with no obvious cause.
`scripts/30-enable-modelcar.sh` does this, backs the ConfigMap up first, and
restarts the controllers (which cache the value at startup, so without a restart
the patch reads as applied and does nothing).
